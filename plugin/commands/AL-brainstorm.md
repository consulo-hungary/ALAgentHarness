In the MAIN chat follow [al-brainstorm](../skills/al-brainstorm/SKILL.md).
Target the active workspace/session working directory, NOT this tagged plugin path.
Launch the real named `al-brainstorm` agent with its configured Opus model, not an
imagined role. Main owns questions and final approval; after direction it launches actual
al-spec to write the numbered draft/index, then approved al-sdd specialist coordination.
Use `$ARGUMENTS` as the idea or explicitly named approved spec, not implied approval.
This is a chat command; `!AL-brainstorm` is shell execution, NOT a safe invocation.
The historical `AL-` name is retained for compatibility; the command detects the active
project profile and routes non-AL work to the generic project SDD workflow.
